# Infografía: Desarrollo Web Moderno

## Descripción

Este proyecto consiste en una infografía web interactiva desarrollada con Spring Boot y Thymeleaf, cuyo objetivo es presentar de forma clara, estructurada y visual los conceptos fundamentales del desarrollo web moderno.

La aplicación funciona como una página estática renderizada desde el servidor, con énfasis en diseño, organización de la información e interactividad en el cliente.

---

## Tecnologías utilizadas

### Backend
- Spring Boot
- Thymeleaf

### Frontend
- HTML5
- CSS3
- JavaScript

---

## Conceptos abordados

La infografía cubre los siguientes temas:

- HTML5: estructura semántica de la web
- CSS3: diseño visual y estilos
- Bootstrap (conceptual): diseño responsive
- JavaScript: interactividad y manipulación del DOM
- Fetch API: comunicación asincrónica con servidores
- JSON: formato de intercambio de datos
- API REST: arquitectura de comunicación entre sistemas

---

## Relación entre tecnologías

La aplicación muestra el flujo lógico del desarrollo web moderno:

HTML5 define la estructura del contenido  
CSS3 aplica estilos y diseño visual  
JavaScript agrega interactividad  
Fetch API permite realizar solicitudes HTTP  
API REST gestiona la comunicación entre cliente y servidor  
JSON se utiliza como formato de datos  

---

## Características principales

- Diseño tipo infografía (contenido resumido y visual)
- Fondo animado con canvas en JavaScript
- Uso de una paleta de colores consistente
- Estructura semántica con HTML5
- Interfaz limpia y organizada
- Separación de responsabilidades (HTML, CSS, JS)
