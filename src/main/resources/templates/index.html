Desarrollo Web Moderno

Infografía sobre el desarrollo web moderno y sus usos

Por Agomez2025379 (rayocrac)

1. HTML V5

  • definicion: lenguaje de marcado para la estructuracion de documentos web.
  • semantica: utiliza etiquetas con significado funcional (nav, main, aside).
  • accesibilidad: estandariza la lectura para tecnologias asistivas.

Ejemplo HTML5:

<header>
    <nav>
        <ul>
            <li><a href="#">Inicio</a></li>
        </ul>
    </nav>
</header>
<main>
    <section>
        <h2>Título</h2>
        <p>Contenido principal</p>
    </section>
</main>
<footer>
    <p>©RAYODEV 2026</p>
</footer>

2. CSS V3

  • definicion: hojas de estilo para la capa de presentacion visual.
  • layout: implementa sistemas de rejilla como flexbox y grid.
  • rendimiento: permite animaciones procesadas por gpu.

Ejemplo CSS3:

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

.box {
    width: 100px;
    height: 100px;
    background: linear-gradient(45deg, #ff6b6b, #4ecdc4);
    border-radius: 10px;
    transition: transform 0.3s ease;
}

.box:hover {
    transform: scale(1.1);
}

3. BOOTSTRAP

  • definicion: framework css para diseño responsivo prioritario en moviles.
  • grid: sistema de 12 columnas que organiza el contenido.
  • estandar: componentes listos para usar basados en flexbox.

Ejemplo Bootstrap:

<div class="container">
    <div class="row">
        <div class="col-md-6">
            <div class="card">
                <div class="card-body">
                    <h5 class="card-title">Título</h5>
                    <p class="card-text">Contenido</p>
                    <a href="#" class="btn btn-primary">Botón</a>
                </div>
            </div>
        </div>
    </div>
</div>

4. JAVASCRIPT

  • definicion: lenguaje de scripting para interactividad en el navegador.
  • dom: interfaz de programacion para manipular elementos html.
  • eventos: gestiona clics, desplazamientos y entradas de datos.

Ejemplo JavaScript:

// Seleccionar elemento
const button = document.querySelector('#myButton');

// Agregar evento click
button.addEventListener('click', function() {
    // Cambiar contenido
    const paragraph = document.querySelector('#myParagraph');
    paragraph.textContent = '¡Texto cambiado!';

    // Cambiar estilo
    paragraph.style.color = 'red';
});

5. fetch api

  • definicion: interfaz para solicitudes http asincronas.
  • asincronia: permite el intercambio de datos sin recargar la pagina.
  • promesas: gestiona las respuestas exitosas o errores del servidor.

Ejemplo Fetch API:

// Hacer una petición GET
fetch('https://api.example.com/users')
    .then(response => response.json())
    .then(data => {
        console.log('Datos recibidos:', data);
        // Procesar los datos
        displayUsers(data);
    })
    .catch(error => {
        console.error('Error:', error);
    });

// Función async/await
async function getUsers() {
    try {
        const response = await fetch('/api/users');
        const users = await response.json();
        return users;
    } catch (error) {
        console.error('Error:', error);
    }
}

6. JSON

  • definicion: formato ligero de texto para representacion de datos.
  • estructura: pares de clave y valor legibles para humanos y maquinas.
  • intercambio: el estandar para la comunicacion entre cliente y servidor.

Ejemplo JSON:

// Objeto JSON
{
    "usuario": {
        "id": 123,
        "nombre": "Juan Pérez",
        "email": "juan@example.com",
        "activo": true,
        "roles": ["admin", "editor"],
        "perfil": {
            "edad": 30,
            "ciudad": "Madrid"
        }
    },
    "productos": [
        {
            "id": 1,
            "nombre": "Producto A",
            "precio": 29.99
        },
        {
            "id": 2,
            "nombre": "Producto B",
            "precio": 49.99
        }
    ]
}

// Parsear JSON en JavaScript
const jsonString = '{"nombre": "Ana", "edad": 25}';
const objeto = JSON.parse(jsonString);
console.log(objeto.nombre); // "Ana"

// Convertir objeto a JSON
const usuario = { nombre: "Carlos", edad: 35 };
const json = JSON.stringify(usuario);

7. API REST

  • definicion: arquitectura de servicios web basada en recursos (urls).
  • metodos: gestion mediante get, post, put y delete.
  • comunicacion: utiliza http como protocolo de transferencia de estado.

Ejemplo API REST:

// Endpoints RESTful
GET    /api/users          // Obtener todos los usuarios
GET    /api/users/123      // Obtener usuario específico
POST   /api/users          // Crear nuevo usuario
PUT    /api/users/123      // Actualizar usuario completo
PATCH  /api/users/123      // Actualizar campos específicos
DELETE /api/users/123      // Eliminar usuario

// Ejemplo de respuesta JSON
{
    "status": "success",
    "data": {
        "user": {
            "id": 123,
            "name": "Juan Pérez",
            "email": "juan@example.com"
        }
    },
    "message": "Usuario creado exitosamente"
}

// Códigos de estado HTTP
200 OK           // Éxito
201 Created      // Recurso creado
400 Bad Request  // Error en la petición
401 Unauthorized // No autorizado
404 Not Found    // Recurso no encontrado
500 Internal Server Error
